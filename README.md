# Star Tech - E-Commerce Homepage (HW 1)

**Star Tech e-commerce homepage layout - front-end development homework (HTML, CSS).**

[![Live Demo](https://img.shields.io/badge/Live_Demo-jotika--meaw.github.io-blue)](https://jotika-meaw.github.io/EBT-FDL-HW-1/)

## About

A static e-commerce homepage for a gadget shop called **Star Tech**, featuring a top navigation, offer banners, product showcase, and a footer. Built with plain HTML as a front-end development lab homework.

## Features

- **Header** with logo, search, offers and account links
- **PC Builder** and product call-out banners
- **Product card** showcase
- **Responsive layout**

## Tech Stack

- HTML5

## Run Locally

```bash
git clone https://github.com/jotika-meaw/EBT-FDL-HW-1.git
cd EBT-FDL-HW-1
```

Open `index.html` in your browser, or serve it locally:

```bash
npx serve .
```
